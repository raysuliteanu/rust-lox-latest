# README

_This is a "backing" Git repo for my jj repo I'm using locally._

This repo contains my WIP for the [CodeCrafters Interpreter](https://app.codecrafters.io/courses/interpreter/overview)
challenge. It's currently implemented up to the ["higher-order functions"](https://app.codecrafters.io/courses/interpreter/stages/ey3)
section.

The Lox grammar is in [Grammar.md](Grammar.md). The grammar is mostly implemented
except for the 'class' and related support. I let my CodeCrafters membership
expire though so I've been lax in continuing Lox.

## Examples

You can see some examples of Lox in the [test](./test) directory. Most are
